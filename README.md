# 🎨 Huiro - Highly Unnecessary, But Inspired by Regulatory Obstacles

**Хуиро? А когда Miro?**

Привет, друг. Знакомо чувство, когда у тебя отбирают любимую игрушку? Вот и мне не понравилось. Поэтому я сделаю свою. С болтами, палками и чёрной магией JavaScript.

## Что это такое?

Huiro — это результат праведного гнева. Это клон Miro, который:

*   **Будет работать.** Иногда.
*   **Будет рисовать фигуры.** Кривые, но с душой.
*   **Позволит colaborate.** Если твой коллега такой же отчаянный, как и ты.
*   **Не будет спрашивать лицензию.** Пока что.

## Чем это лучше Miro?

| Особенность | Miro | Huiro |
|-------------|------|-------|
| Подписка | Дорого | Бесценно (бесплатно) |
| Техподдержка | Есть | Я сам себе техподдержка |
| Стабильность | Высокая | Напоминает дженгу в ураган |
| Чувство собственного достоинства | Есть | Будет утрачено в процессе разработки |
